Freelancer Project — WhatsApp Bot Ecosystem Simulator
A high-fidelity, interactive simulation engine demonstrating an end-to-end conversational logistics platform built on a decoupled 5-Bot Architecture pattern. This project highlights real-time transactional state management, advanced database concurrency safeguards, and complex workflow automation entirely within mobile-first chat interfaces.
